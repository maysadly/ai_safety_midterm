# Notes added after the measurement above (2026-10-22)
- Prompt-eval times above are small because Ollama reuses the KV cache for a repeated prompt.
  Uncached long prompt on qwen2.5:3b-instruct (1237 tokens, 2 runs): 408 and 436 tok/s
  prompt processing; generation 40 tok/s; 5.3-6.3 s per request in total.
- Memory: Ollama limits loaded models by free *system* memory (log: "system_limited=true",
  ~5.9 GiB free at start with other apps open). Bot (3B, 2.2 GB) + guard (1B, 1.2 GB) stay
  loaded together; loading the 7B judge (4.6 GiB predicted) evicts them
  ("model predicted to exceed available memory, evicting" in logs/ollama.log).
  Consequence for the experiment: the judge runs as a separate pass after the chat requests.
